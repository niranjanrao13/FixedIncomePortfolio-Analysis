# Fixed-Income Portfolio Risk Factor Analysis with PCA and Regression
Identifying and analying key factors impacting fixed-income portfolios like credit spread, using PCA and regression analysis.

## Getting started
Install the requirements specified in `requirements.txt` 
```
pip install -e requirements.txt
``` 
in the root folder.

Create a `.venv` before, not mandatory but recommended.
